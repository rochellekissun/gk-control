Account sign-up, sign-in, password reset and private sync need a Supabase project. Add its project URL and public anon key below. Never enter a service-role key.

SETUP NOTES

  1. Create a Supabase project on its free plan.
  2. Run the included schema.sql in the SQL editor.
  3. Copy the Project URL and public anon key from Project Settings → API.
  4. Set the GitHub Pages address as an allowed redirect URL in Authentication settings.

Free projects can pause after inactivity. The default auth email service has low best-effort limits. See the setup guide for current limits.
